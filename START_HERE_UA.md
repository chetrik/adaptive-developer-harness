# Початок роботи з Adaptive Developer Harness

**Статус:** це стартове ТЗ для розробки генератора, а не готовий продукт. Генерацію Harness ще потрібно реалізувати.

## Для чого

Користувач описує, який продукт хоче створити, та за потреби надає доступ до існуючого репозиторію. Coding agent допомагає оцінити масштаб, знайти готові рішення, пояснює ключові рішення, пропонує налаштування процесу розробки, а після підтвердження створює потрібні файли, Skills, субагентів і перевірки.

Користувачу не потрібно знати наперед, що таке ADR, TDD, C4, Hooks або RAG. Агент пояснює поняття тоді, коли воно впливає на рішення.

## Як почати розробку самого генератора

1. Створити **порожній приватний або публічний GitHub-репозиторій** із робочою назвою `adaptive-developer-harness` (ім'я можна змінити).
2. Завантажити до нього вміст цього архіву, зберігши структуру папок.
3. Відкрити репозиторій у Codex або іншому coding agent.
4. Передати агенту текст [CODEX_BOOTSTRAP_PROMPT.md](CODEX_BOOTSTRAP_PROMPT.md).
5. Спочатку погодити архітектуру й MVP, після цього доручити реалізацію поетапно.
6. Перевіряти результати на контрольних сценаріях із [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).

## Майбутній шлях кінцевого користувача

1. «Хочу створити CRM для туристичної агенції» — цього достатньо для початку розмови.
2. Агент уточнює лише суттєві невідомі деталі; за можливості перетворює опис або голосовий потік на PRD.
3. Пропонує наявні open-source рішення/готові сервіси та розраховує ризики адаптації.
4. Показує зрозумілий Harness Plan: які компоненти потрібні, чому, що не буде створено, які дії потребують дозволу.
5. Після явного погодження створює або оновлює файли проєкту, не руйнуючи існуючі.
6. Перевіряє зміни й залишає користувачеві коротку інструкцію, як продовжити роботу в наступній сесії або іншому агенті.

**Увага:** доступ до GitHub, робота з файлами, запуск скриптів і створення subagents залежать від інструментів конкретного coding agent. Просте посилання на репозиторій не дає автоматично прав на читання/запис або виконання команд.

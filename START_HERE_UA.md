# Початок роботи

Передайте своєму coding agent дві речі:

1. PRD — файл із описом вашого застосунку.
2. Посилання: https://github.com/chetrik/adaptive-developer-harness

Можна написати: «Прочитай мій PRD і BOOTSTRAP.md у цьому репозиторії. Допоможи вибрати мінімальний Developer Harness, поясни план і дочекайся погодження перед змінами».

Агент перевірить доступ, прочитає вимоги, дослідить готові рішення, коли це доречно, і покаже, які Skills та правила потрібні й навіщо. Ви погоджуєте конкретні зміни; технічні команди виконує агент. Обов’язкового CLI для користувача немає.

Для наявного застосунку потрібна доступна робоча папка. Для нового не потрібен третій репозиторій: агент запропонує місце створення. Якщо GitHub недоступний або фактів бракує, він пояснить обмеження. Не потрібно створювати другий репозиторій самого генератора.

MVP уже містить виконуваний планувальник, погодження, генерацію вибраних компонентів і перевірки. Він не пише весь застосунок і не гарантує його безпеку. Підтримка конкретних можливостей агента перевіряється окремо.

Детальний протокол для агента: [BOOTSTRAP.md](BOOTSTRAP.md). Фактичні перевірки та обмеження: [docs/VERIFICATION.md](docs/VERIFICATION.md).
